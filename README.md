# 问题笔记本 (Question Notebook)

一个基于 Python 命令行的问题记录工具。把平时遇到的技术问题、学习疑问随手记下来，解决了就标记状态、写上解决方案，方便日后回顾。

## 功能特性

- ➕ **添加问题**：记录标题和详细描述
- 📋 **查看全部**：按列表展示所有问题，含状态和时间
- ✅ **标记已解决**：为问题补充解决方案/心得
- 🗑️ **删除问题**：按 ID 删除（带二次确认，防误删）
- 🔍 **搜索问题**：按关键词匹配标题、描述、解决方案（忽略大小写）
- ✏️ **编辑问题**：修改标题、描述、解决方案（回车跳过表示不改）
- 💾 **自动持久化**：数据以 JSON 格式保存在本地，重启不丢失

## 环境要求

- Python 3.x（无需安装任何第三方库）

## 使用方法

在项目目录下运行：

```bash
python question_notebook.py
```

启动后进入主菜单：

```
=========================
     问题笔记本主菜单
=========================
  1. 查看所有问题
  2. 添加新问题
  3. 标记问题为已解决
  4. 删除问题
  5. 搜索问题
  6. 编辑问题
  0. 退出程序
=========================
```

输入对应数字编号即可操作。首次运行会自动创建 `questions.json` 数据文件。

## 数据存储

所有问题保存在同目录下的 `questions.json` 中，格式如下：

```json
{
    "id": 1,
    "title": "问题标题",
    "description": "问题详细描述",
    "timestamp": "2026-07-24 11:10:38",
    "is_solved": false,
    "solution": "解决方案（未解决时为空字符串）"
}
```

| 字段 | 说明 |
|------|------|
| `id` | 问题唯一编号，程序自动分配，自增 |
| `title` | 问题标题 |
| `description` | 问题详细描述，可为空 |
| `timestamp` | 创建时间（`年-月-日 时:分:秒`） |
| `is_solved` | 是否已解决（`true` / `false`） |
| `solution` | 解决方案或心得，未解决时为空 |


## 代码结构说明

- `Question` 类：问题数据模型，包含标题、描述、状态、解决方案、创建时间等属性
- `save_questions()`：将问题列表序列化写入 JSON（含 ID 自动分配逻辑）
- `load_questions()`：从 JSON 加载问题列表，文件不存在时返回空列表
- `add_question()` / `list_questions()` / `solve_question()` / `delete_question()` / `search_questions()` / `edit_question()`：对应六大功能
- `main()`：程序入口，菜单循环 + 用户交互
